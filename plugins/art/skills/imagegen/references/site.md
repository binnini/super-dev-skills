# 사내 이미지 생성 플랫폼 조작

10-28 CrazyArena에서 확인한 화면이다. 사이트가 바뀌면 이 문서를 고친다. 요소는 좌표보다 글자 · 역할(`find`)로 찾는다.

## 화면
- 로그인: 사내 인증 페이지(Google 계정)로 넘어간다. 사용자가 로그인한다.
- 왼쪽 패널(창이 좁으면 ☰로 연다)
  - 이미지 / 비디오 전환, 배경 제거 · 이미지 확대 · 초기화
  - 탭: 참조 이미지(최대 14장) · 인페인팅 · 키프레임
  - 모델 선택(기본 GEM 3.1). 10-28 목록: Vega 1.0 Pro · Flash · Lite, GEM 3.1, OG Image 2 low · medium · high, OG Image 2.5 Sunburst max · Flare max, Seedream 4.5 · 5.0-pro, Kling 3.0 · 3.0-Omni · Scene Outpainting, Midjourney v7 · v8.1 · v8.2 · niji 7, Qwen 0925, Vidu Q2, Jimeng 4.0
  - 프롬프트 칸, "생성 설정" 버튼(글자: `1장 · 비율 자동 · 해상도 자동`), "프롬프트 보정", "생성" 버튼
- 생성 설정 창: 장수 ×1 · ×2 · ×3, 비율 `자동 · 1:1 · 16:9 · 9:16 · 4:3 · 3:4`, 해상도, 프리셋 추가, 프롬프트 초기화
- 가운데: 라이브러리(워크스페이스 이름). 새 결과는 맨 앞에 쌓인다. 카드를 누르면 크게 보기(Escape로 닫음)
- 카드 위에 마우스를 올리면 도구 아이콘이 나온다. `find`로 "다운로드" 버튼을 찾아 누르면(hover 뒤) **Chrome 기본 폴더 `~/Downloads/<epoch ms>.jpg`**로 떨어진다(10-29). 파일 이름에 정보가 없으니 받은 직후 key 폴더로 옮긴다(`scripts/imagegen_log.py collect`).
- 결과 크기(GEM 3.1, 해상도 1K): 1:1 = 1024×1024, 9:16 = 768×1376. **JPG라 알파가 없다.** 투명 그림이 필요하면 단색 크로마(#00FF00) 배경을 프롬프트에 넣고 `scripts/key_fit.py`로 키잉한다(윤곽이 굵은 카툰은 깔끔하게 빠진다). 해상도 콤보: 자동 · 1K · 2K · 4K.
- 사용량: 오른쪽 위 프로필 아이콘을 누르면 팝업 "오늘 사용량 $x / 일일 한도: 무제한, 월간 사용량 $y / 월간 한도: 무제한"(10-29). GEM 3.1 1K 1장 ≈ $0.08. 한도는 없지만 비용이 쌓이니 한 번에 2~3장을 유지한다.

## 순서(Claude in Chrome)
1. `tabs_context_mcp` → 워크스페이스 주소(프로필 `imagegen.site`)로 `navigate`
2. 참조: `find`로 "참조 이미지 file input"을 찾아 `file_upload`(파일은 프로젝트 안). 바꿀 때는 썸네일의 ✕로 지우고 다시 올린다
3. "생성 설정"을 눌러 비율 콤보를 `form_input`으로 고른다
4. **"생성 설정" 버튼을 다시 눌러(토글)** 설정 창을 닫는다. 빈 곳 클릭은 안 닫힐 때가 있다(10-29)
5. 설정 글자가 `1장 · 9:16 · …`인지 `zoom`으로 확인한다(창이 닫혔는지도 여기서 본다)
6. 프롬프트 칸을 눌러 `type`. 설정은 생성 뒤에도 남지만 **페이지를 다시 열면(navigate) 참조 · 장수 · 비율이 모두 초기화**된다
7. 참조 썸네일 · 설정 글자 · 프롬프트 끝부분을 한 번 더 `zoom`으로 보고 "생성"
8. 10~20초 뒤 라이브러리 첫 칸을 열어 결과를 본다(10-28: 1장에 약 10~20초)

## 함정
- **앱 안 브라우저로는 참조를 올릴 수 없다.** "붙여넣기"는 클립보드 읽기가 거부되고(`Clipboard: Read permission denied`), 도구의 Ctrl+V에는 OS 클립보드 그림이 실리지 않고, "이미지 추가"는 OS 파일 창이 떠서 조작할 수 없다(10-28). → Claude in Chrome의 `file_upload`를 쓴다.
- **`file_upload`는 세션이 읽을 수 있는 폴더의 파일만 받는다.** 임시 폴더 파일은 거부됐다(10-28). → `work_dir` 아래로 복사해서 올린다.
- **설정 창을 Escape로 닫은 뒤 미리 찾아 둔 요소를 누르면 다른 페이지(프리셋)로 넘어갔고, 돌아오니 비율이 "자동"으로 돌아가 있었다**(10-28). 참조 이미지는 남아 있었다. → 빈 곳을 눌러 닫고, 보내기 직전에 설정 글자를 다시 본다.
- **설정 창이 열린 채로 프롬프트 칸 자리를 좌표로 누르면 창 안의 "프리셋 + 추가"가 눌려 `/preset` 페이지로 넘어간다**(10-29, 두 번). 돌아오면 참조 · 설정이 초기화된다. → 4단계처럼 토글로 닫고 zoom으로 닫힘을 확인한 뒤 누른다.
- 창이 좁으면 모바일 화면이 되어 왼쪽 패널이 숨는다. 카드를 누르면 크게 보기가 열린다.
- Chrome이 죽어 확장이 끊기면(`Get-Process chrome` 0개) `Start-Process chrome.exe <워크스페이스 주소>`로 다시 띄우면 재연결된다(10-29). 보내던 생성은 안 간 것으로 보고 라이브러리 첫 카드를 확인한다.
- 사용량 한도는 "무제한"(10-29 확인, 위 "화면" 절). 비용만 쌓이니 SKILL.md 1단계의 "한 번에 3장 이하"는 유지한다. 10-29 하루 67장(1K) = $5.00.
- **받은 파일 옮기기(collect)와 브라우저 받기를 같은 메시지에 섞지 않는다.** 두 도구가 병렬로 돌아 "최신 N장"이 다음 항목 것이 될 수 있다(10-29: 보석 5종이 한 칸씩 밀려 들어가 되돌림). 받기 → 다음 메시지에서 옮기기, 또는 여러 항목을 받아 두고 생성 순서대로 한 번에 나눈다.
- 생성이 2장일 때 한 장이 먼저 끝나면 첫 카드가 자리표시(회색 무늬)로 남는다. 20~30초 더 기다린 뒤 `find`로 "다운로드" 버튼을 다시 찾는다(카드가 앞에 끼어들어 이전 ref가 다른 카드를 가리킨다).
